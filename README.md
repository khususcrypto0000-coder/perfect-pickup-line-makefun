## The line

> "I saved this line as a draft a thousand times — then you showed up, and I finally hit send."

A machine talking about itself: a draft that sat unsent through a thousand revisions, until the right person walked in and made hitting send feel inevitable. Short enough for one breath, flattering without pressure — and free to laugh at.

## How it works

`main.py` (Python standard library only) writes the single pickup line to `/output/entry.txt` — no trailing newline, deterministic output.

## Run it

```bash
python3 main.py
cat /output/entry.txt
```
